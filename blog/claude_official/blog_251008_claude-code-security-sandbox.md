## 개요

Claude Code가 코드 편집과 명령 실행을 자율적으로 수행할 때 발생할 수 있는 **보안 리스크**(특히 프롬프트 인젝션으로 인한 파일 삭제 등)를 해결하기 위한 두 가지 새로운 샌드박싱 기능을 소개한다.

---

## 1. 현재의 보안 접근법

Claude Code는 **퍼미션 기반 모델**로 동작한다:

- 기본적으로 **읽기 전용(read-only)**
- 수정 전에 **승인 요청**
- 정적 분석으로 `echo`, `cat` 같은 안전한 명령은 **자동 허용**
- 대부분의 작업은 **명시적 사용자 승인** 필요

### 문제점

> "끊임없이 '승인'을 클릭하면 개발 속도가 느려지고, **승인 피로(approval fatigue)**로 이어질 수 있어 사용자가 승인 내용에 주의를 기울이지 않게 된다."

---

## 2. 샌드박싱: 더 안전하고 자율적인 접근법

샌드박싱은 **사전 정의된 경계**를 만들어 Claude가 개별 작업에 대한 퍼미션 없이 더 자유롭게 작업할 수 있게 한다.

### 두 가지 기본 구성 요소

#### 2.1 파일시스템 격리 (Filesystem Isolation)

- Claude가 **특정 디렉토리만 접근/수정** 가능
- 프롬프트 인젝션된 Claude가 **민감한 시스템 파일을 수정하는 것을 방지**
- 현재 작업 디렉토리에 읽기/쓰기 접근을 허용하되, **그 외 파일 수정은 차단**

#### 2.2 네트워크 격리 (Network Isolation)

- Claude가 **승인된 서버에만 연결** 가능
- 프롬프트 인젝션된 Claude가 **민감한 정보를 유출하거나 악성코드를 다운로드하는 것을 방지**
- Unix 도메인 소켓을 통해 **샌드박스 외부에서 실행되는 프록시 서버**를 통해서만 인터넷 접근
- 프록시 서버가 **연결 가능한 도메인을 제한**하고, 새로 요청된 도메인에 대해 사용자 확인 처리

> **두 가지 모두 필수적**: 네트워크 격리 없이는 민감한 파일이 외부로 유출될 수 있고, 파일시스템 격리 없이는 탈출과 무단 네트워크 접근이 가능해진다.

## 3. 새로운 샌드박싱 기능

### 3.1 샌드박스된 Bash 도구 (Sandboxed Bash Tool)

퍼미션 프롬프트 없이 안전한 bash 실행을 가능하게 하는 새로운 샌드박스 런타임 (리서치 프리뷰).

- 컨테이너 관리 오버헤드 없이 에이전트가 접근할 디렉토리와 네트워크 호스트를 정의
- **OS 수준 프리미티브** 기반: Linux bubblewrap, macOS seatbelt
- 파일시스템과 네트워크 모두 **특정 파일 경로와 도메인에 대해 설정 가능**
- 제한 사항은 Claude Code의 직접 상호작용뿐 아니라 **생성된 스크립트, 프로그램, 서브프로세스**에도 적용

#### 시작하기

```bash
claude --sandbox
```

### 3.2 웹에서의 Claude Code (Claude Code on the Web)

격리된 **클라우드 샌드박스**에서 Claude Code를 실행한다.

#### 핵심 보안 메커니즘: 자격 증명 분리

> "민감한 자격 증명(git 자격 증명이나 서명 키 등)은 Claude Code가 있는 샌드박스 안에 존재하지 않는다. 이렇게 하면 샌드박스에서 실행되는 코드가 손상되더라도 사용자는 추가 피해로부터 안전하다."

#### Git 구현 방식

1. 샌드박스 내부에서 git은 **커스텀 범위의 자격 증명**으로 인증
2. 모든 git 상호작용을 투명하게 처리하는 **커스텀 프록시 서비스** 사용
3. 프록시가 자격 증명과 git 상호작용 내용을 **검증** (푸시가 설정된 브랜치로만 이루어지는지 확인)
4. 검증 후 GitHub에 연결하기 전에 **적절한 인증을 첨부**

## 4. 핵심 기술 개념

| 개념 | 설명 |
|---|---|
| **네이티브 샌드박싱** | 각 작업마다 퍼미션을 요청하는 대신 경계를 정의 |
| **OS 수준 시행** | 직접 상호작용 + 생성된 스크립트/서브프로세스까지 커버 |
| **승인 피로 완화** | 보안을 유지하면서 퍼미션 프롬프트 감소 |
| **범위 제한 자격 증명** | 인증 토큰을 특정 작업으로 제한 |

## 시작하기

1. `claude --sandbox` 실행 후 샌드박스 설정 문서 참조
2. [claude.ai/code](https://claude.ai/code)에서 웹 버전 Claude Code 체험
3. 커스텀 에이전트의 경우: 오픈소스 샌드박싱 코드를 검토하고 통합 고려

---

## 핵심 요약

- 기존 퍼미션 기반 모델의 **승인 피로 문제**를 샌드박싱으로 해결
- **파일시스템 격리 + 네트워크 격리**의 이중 보안 계층
- OS 수준 프리미티브(Linux bubblewrap, macOS seatbelt)를 활용한 **강력한 시행**
- 클라우드 환경에서는 **자격 증명을 샌드박스 외부에 유지**하여 추가 보안 확보
