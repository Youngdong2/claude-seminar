## 개요

AI 코딩 도구가 줄 단위 제안에서 **전체 개발 작업을 자율적으로 실행**하는 수준으로 급속히 변화했다. 코드베이스 전체를 분석하고, 테스트를 실행하며, 목표가 달성될 때까지 반복하는 시스템으로 진화했다.

## 1. 에이전틱 코딩이란?

AI를 자동완성 기능에서 **자율 작업 실행자**로 재포지셔닝하는 것.

| 전통적 코딩 어시스턴트 | 에이전틱 시스템 |
|----------------------|----------------|
| 사용자 입력 대기 후 연속 제안 | 상위 목표를 수용하여 분해, 독립 실행 |
| 보이는 코드를 검사하여 조각 제안 | 전체 코드베이스 읽기, 파일 간 관계 이해 |
| 현재 파일/인접 파일만 검토 | 명령 실행으로 변경 검증 |
| 제한된 컨텍스트 윈도우 | 테스트 통과 및 요구사항 충족까지 반복 |

**핵심 차이**: **자율성(autonomy)과 범위(scope)**

## 2. AI 코딩 도구의 진화

### 1단계: 코드 예측 및 자동완성
- IDE 자동완성 확장이 보이는 코드를 분석하여 예측
- 반복 패턴에 탁월: REST 엔드포인트 템플릿, 테스트 구조, 공통 알고리즘
- **한계**: 컨텍스트 윈도우가 현재 파일/인접 파일로 제한. 앱 아키텍처 전반의 데이터 흐름이나 크로스 서비스 의존성 이해 불가

### 2단계: 대화형 AI 채팅 인터페이스
- 브라우저 기반 어시스턴트에 대화 기능 추가
- 코드 문제 토론, 스니펫 붙여넣기, 버그 설명, 최적화 질문 지원
- 반복적 개선과 분석/가이드에 탁월
- **한계**: 다중 파일 구현 조율이 수동 (파일 붙여넣기, 수정 추적, 복사, 일관성 확인)

### 3단계: 에이전틱 코딩
- 2단계의 한계를 해결하는 시스템

## 3. 에이전틱 코딩의 작동 방식

### 컨텍스트 수집 및 계획
- **파일 레벨이 아닌 프로젝트 레벨**에서 작동
- 목표를 받으면 설정 파일, 테스트 파일 읽기, import 추적으로 의존성 매핑
- 정보 수집에 따라 **진화하는 적응적 계획** 생성

**예시 - "API에 인증 추가":**
1. 라우트 정의 분석
2. 보호가 필요한 엔드포인트 식별
3. 기존 인증 미들웨어 확인
4. 세션 관리 위치 결정

### 구현 및 조율
- 코드베이스 전반에서 파일 읽기/쓰기
- 단일 파일이 아닌 **다중 관련 파일 수정**으로 일관성 유지

**인증 추가 시 수정 대상:**
- 라우트 핸들러 업데이트
- 미들웨어 생성
- 스키마 수정
- 클라이언트 코드 조정
- 문서 업데이트
- 테스트 추가

**개발 패러다임 전환:**
- 기존: "코드 작성 -> 테스트 실행 -> 오류 읽기 -> 수정 -> 반복"
- 에이전틱: **"목표 정의 -> 제안된 변경 검토 -> 구현 승인"**

## 4. Claude Code

### 설치 및 실행

```bash
npm install -g @anthropic-ai/claude-code
```

프로젝트 디렉토리에서 실행:

```bash
claude
```

### Claude Code 작동 방식
- **전체 프로젝트 컨텍스트** 읽기
- 파일 구조 분석, package.json/requirements.txt의 의존성 이해
- 모듈 상호작용 추적, 확립된 패턴 식별

### 다중 파일 작업 예시
- 요청: "콜백 기반 코드를 async/await로 리팩터링"
- Claude Code 수행:
  1. 콜백 사용 파일 전체 식별
  2. 각 파일을 async/await 구문으로 업데이트
  3. 에러 처리를 try/catch 블록으로 수정
  4. 테스트를 async 패턴으로 업데이트
  5. 테스트 스위트 통과 검증

### 파일 시스템 접근 및 권한
- 웹 기반 도구가 처리할 수 없는 워크플로우 지원
- 적절한 네이밍으로 새 파일 생성, 코드 논리적 조직화
- 의존성 추가 시 설정 파일 업데이트
- **권한 모델**: 기본적으로 파일 수정 전 승인 요청, 정확한 변경 사항 표시

### 개발 워크플로우 통합
- npm 명령으로 의존성 설치
- 테스트 러너 실행 (Jest, pytest)
- Git으로 커밋 및 브랜칭
- 개발 서버 시작하여 변경 동작 확인
- **MCP(Model Context Protocol) 서버** 연결로 기능 확장 가능

## 5. 실제 적용 사례: Rakuten
