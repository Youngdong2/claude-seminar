## 개요

에이전틱 코딩(Agentic Coding)을 개별 실험 단계에서 조직 전체로 확장하는 방법론을 다룬 포스트. 성공적인 도입은 도구 선택보다 **실행(execution)**에 달려 있으며, 체계적인 배포가 개발 속도와 엔지니어 만족도에 의미 있는 개선을 이끌어낸다고 강조한다.

---

## 1. 에이전틱 코딩의 이해

에이전틱 도구는 기본 코드 완성(code completion)과 달리 **멀티스텝 태스크**를 더 넓은 컨텍스트 인식으로 처리하며, 사용자 개입을 줄인다.

### 주요 활용 사례

| 활용 분야 | 설명 |
|---|---|
| **레거시 모더나이제이션** | 코드베이스 마이그레이션을 현재 플랫폼으로 가속화 |
| **빠른 온보딩** | 신규 엔지니어가 코드베이스를 쿼리하여 아키텍처와 패턴 이해 |
| **인시던트 대응** | SRE/DevOps 에이전트가 운영 이슈를 진단하고 대응 |
| **기술적 참여 확대** | PM, 디자이너가 제약 조건을 탐색하고 프로토타입 생성 |

---

## 2. 확장 접근법 계획

### 2.1 슈퍼 유저(Super Users)로 시작

이미 AI 도구를 사용 중인 **20~50명의 개발자**로 시작한다.

- 데이터베이스 마이그레이션이나 스캐폴딩을 위한 **커스텀 슬래시 커맨드** 생성
- 코딩 표준을 담은 **CLAUDE.md 파일** 작성
- 자동화할 가치 있는 **반복 워크플로우** 식별
- 전용 **트러블슈팅 채널** 설정
- 서드파티 인증을 위한 **래퍼 스크립트** 개발

### 2.2 해커톤으로 런칭

파일럿 사용자가 기술을 공유하면서 다른 사람들이 **저위험(low-stakes) 환경**에서 실험하는 협업 이벤트를 활용한다. 이 형식은 직접 체험을 통해 회의론자를 전환시킨다.

### 2.3 내부 전문성을 통한 확장

파일럿 멤버가 조언 역할로 전환하여 워크숍을 운영하고 내부 리소스로 활동한다. 컨텍스트의 관련성 때문에 외부 교육보다 효과적이다.

## 3. CLAUDE.md 파일 효과적으로 활용하기

### 모범 사례

- CLAUDE.md를 **리포지토리 루트에 체크인**하여 자동 상속
- 아키텍처 변경과 함께 업데이트하는 **살아있는 문서**로 취급
- 개발자 **온보딩 체크리스트**에 포함
- 패턴이 크게 다른 경우 **브랜치별 변형** 유지

### 일반적인 포함 내용

- 개발 환경 요구사항
- 테스팅 표준
- 아키텍처 패턴
- 현재 중점 영역

---

## 4. 영향 측정

### 성공 지표 (코드 줄 수를 넘어서)

- **스프린트 처리량** 상관관계
- **태스크 완료 시간** 개선
- **마이그레이션 속도** 가속
- **개발자 만족도 설문** (창의적 vs 반복적 작업 시간)
- **온보딩 기간** 단축
- **교차 기능** 효율성 향상

> Claude Code에는 코드 수락률, 일일 활성 사용자 및 세션, 지출 데이터, 개별 개발자 메트릭을 추적하는 **Activity Metrics**가 포함되어 있다.

## 5. 일반적인 도입 과제

### 5.1 태스크 범위를 적절히 설정하라

**테스트 주도 개발(TDD)**을 사용하여 명확한 성공 기준을 제공한다.

#### 프로세스

1. 필요한 기능과 엣지 케이스를 정의하는 **테스트 작성**
2. 한 번에 하나의 테스트씩 **점진적으로 기능 구현**
3. 각 단계 후 **테스트 실행**
4. 새로운 테스트를 통해 **요구사항을 점진적으로 추가**

#### 예시

```
# 좋은 접근법 (단계적)
"write tests for user registration"
-> "implement the registration logic to pass these tests"

# 나쁜 접근법 (한 번에 모든 것을 요청)
"build the entire user registration system with all edge cases"
```

### 5.2 충분한 컨텍스트를 제공하라

모호한 설명 대신 구체적 정보를 제공한다:

- **완전한 에러 메시지**와 스택 트레이스 공유
- **환경 세부사항** 문서화 (OS, 언어 버전, 의존성)
- UI 이슈의 경우: **스크린샷**과 정확한 설명 제공
- **예상 동작 vs 실제 동작** 명확히 명시
- 관련 **파일 내용**과 코드 스니펫 포함

## 핵심 요약

1. 파일럿 그룹과 내부 전문성 개발을 통한 **체계적 확장**
2. CLAUDE.md 파일을 통한 **종합적 컨텍스트 문서화**
3. 생산성 메트릭을 넘어선 **다양한 성공 지표**
4. TDD를 활용한 **적절한 태스크 범위 설정**
5. 충분한 구현 컨텍스트를 제공하는 **명확한 커뮤니케이션**
