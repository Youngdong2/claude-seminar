## 핵심 요약

Anthropic이 Claude의 **Cowork 제품 및 플러그인 에코시스템** 업데이트를 발표했다. 플러그인은 **"모든 역할과 부서를 위한 전문 에이전트"**로, 조직 내 배포를 위한 프라이빗 마켓플레이스 기능이 추가되었다. 2026년 2월 24일 The Briefing: Enterprise Agents 이벤트에서 공개되었다.

---

## 1. 플러그인 및 커스터마이제이션 개선

| 기능 | 설명 |
|------|------|
| **스타터 템플릿** | 관리자가 템플릿에서 플러그인 구성 또는 Claude의 가이드 설정으로 커스텀 빌드 |
| **통합 "Customize" 메뉴** | 플러그인, 스킬, 커넥터를 하나의 메뉴로 통합 |
| **커넥터 디렉토리 강화** | 간소화된 관리자 제어 |
| **조직 전용 마켓플레이스** | 프라이빗 GitHub 리포지토리 지원 (비공개 베타) |
| **사용자별 프로비저닝** | 자동 설치 기능 |
| **슬래시 명령** | 구조화된 양식(form)으로 실행 |

---

## 2. 새로 추가된 커넥터

- **Google Workspace**: Calendar, Drive, Gmail
- **비즈니스/영업**: Docusign, Apollo, Clay, Outreach
- **데이터/분석**: Similarweb, MSCI, FactSet
- **기타**: LegalZoom, WordPress.com, Harvey

### 플러그인 파트너
- Slack by Salesforce
- LSEG, S&P Global
- Common Room, Tribe AI

---

## 3. 신규 사전 빌드 플러그인 템플릿 (10개)

| 역할 | 주요 기능 |
|------|----------|
| **HR** | 제안서, 온보딩, 성과 리뷰, 보상 관리 |
| **디자인** | UX 워크플로, 비판 프레임워크, 접근성 감사, 리서치 계획 |
| **엔지니어링** | 스탠드업 요약, 인시던트 대응, 배포 체크리스트 |
| **운영** | 문서화, 벤더 평가, 런북 |
| **브랜드 보이스** (Tribe AI) | 보이스 가이드라인 추출 및 적용 |
| **재무 분석** | 리서치, 모델링, PowerPoint 품질 확인 |
| **투자 은행** | 거래 리뷰, 비교 분석, 피치 자료 |
| **주식 리서치** | 실적 파싱, 재무 모델, 리서치 노트 |
| **사모펀드** | 딜 소싱, 실사, 시나리오 모델링, 기회 스코어링 |
| **자산 관리** | 포트폴리오 분석, 드리프트 식별, 리밸런싱 추천 |

---

## 4. 멀티앱 통합

- Claude가 **Excel과 PowerPoint 간에 컨텍스트를 전달**하며 오케스트레이션
- 엔드투엔드 워크플로 지원
- Mac/Windows의 모든 유료 플랜에서 **리서치 프리뷰**로 제공
