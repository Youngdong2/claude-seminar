---

## 핵심 요약

Claude Code에 **에이전트 팀 기반의 심층 코드 리뷰 시스템**이 추가되었다. Anthropic 내부에서 거의 모든 PR에 적용하던 시스템을 외부에 공개한 것으로, Team 및 Enterprise 플랜에서 리서치 프리뷰로 제공된다.

---

## 1. 문제: 리뷰 병목 현상

- Anthropic 엔지니어의 코드 출력이 지난 1년간 **200% 증가**
- 코드 리뷰가 병목이 되어 많은 PR이 **대충 훑어보기(skim)** 수준에 그침
- 고객사에서도 동일한 문제 보고

---

## 2. 동작 방식

1. PR이 열리면 **에이전트 팀을 배치(dispatch)**
2. 에이전트들이 **병렬로 버그 탐색**
3. **오탐(false positive)** 필터링을 위한 버그 검증
4. 심각도별 **버그 순위 매기기**
5. 결과물: PR에 **단일 고신호 개요 코멘트** + **인라인 코멘트** (특정 버그별)

### 리뷰 규모 조정
- 대규모/복잡한 변경: 더 많은 에이전트, 깊은 리뷰
- 사소한 변경: 경량 패스
- 평균 리뷰 소요 시간: 약 **20분**

---

## 3. 내부 운영 실적

| 지표 | 수치 |
|------|------|
| 이전 실질적 리뷰 코멘트 비율 | **16%** |
| Code Review 도입 후 | **54%** |
| 대규모 PR (1,000줄+) 발견율 | **84%** (평균 7.5건) |
| 소규모 PR (50줄 미만) 발견율 | **31%** (평균 0.5건) |
| 부정확 판정 비율 | **1% 미만** |

> Code Review는 PR을 **승인(approve)하지 않는다** -- 그것은 여전히 사람의 판단이다.

---

## 4. 실제 사례

### 사례 1: 인증 서비스 한 줄 변경
- 일상적으로 보이는 한 줄 변경이 프로덕션 서비스의 **인증을 파괴**할 뻔했음
- Code Review가 **critical로 플래그**
- 엔지니어: "혼자서는 발견하지 못했을 것"

### 사례 2: TrueNAS ZFS 암호화 리팩토링
- PR이 접촉한 인접 코드에서 **기존 버그 발견**
- 타입 불일치로 인해 동기화할 때마다 **암호화 키 캐시가 지워지는** 잠재 이슈
- 변경 세트를 스캔하는 인간 리뷰어가 즉시 찾기 어려운 종류의 문제

---

## 5. 비용 및 제어

- 기존 Claude Code GitHub Action보다 **더 비싸지만 더 깊은** 리뷰
- 토큰 사용량 기반 과금
- 평균 리뷰 비용: **$15~$25** (PR 크기/복잡도에 따라 조정)

### 관리자 제어 기능

| 기능 | 설명 |
|------|------|
| **월간 조직 한도** | 전체 리뷰 월간 총 지출 정의 |
| **리포지토리 수준 제어** | 선택한 리포지토리에만 리뷰 활성화 |
| **분석 대시보드** | 리뷰된 PR 수, 수락률, 총 리뷰 비용 추적 |

---

## 6. 시작하기

- **플랜**: Team 및 Enterprise (리서치 프리뷰, 베타)
- **관리자**: Claude Code 설정에서 Code Review 활성화 -> GitHub App 설치 -> 리포지토리 선택
- **개발자**: 활성화 후 새 PR에 자동 실행, 별도 설정 불필요
