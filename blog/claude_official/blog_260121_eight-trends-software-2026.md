## 개요

코딩 에이전트가 수동적 도구에서 능동적 협력자로 변모하고 있다. 엔지니어링 팀은 코드를 직접 작성하는 것에서 **코드를 작성하는 에이전트를 조율(orchestrating)**하는 것으로 전환하며, 아키텍처, 시스템 설계, 전략적 결정에 전문성을 집중한다.

### 핵심 수치
- 개발자의 **~60%** 업무에서 AI 사용
- 그러나 **"완전 위임" 가능한 작업은 0-20%**에 불과
- AI는 감독, 검증, 인간의 판단이 필요한 **상시 협력자(constant collaborator)** 역할

## Foundation Trends: 기반 트렌드

### Trend 1: 소프트웨어 개발 라이프사이클의 극적 변화

**핵심 예측:**
- **추상화의 진화**: 코드 작성, 디버깅, 유지보수의 전술적 작업이 AI로 이전. 엔지니어는 아키텍처, 시스템 설계, 전략적 결정에 집중
- **엔지니어링 역할 전환**: 소프트웨어 엔지니어 = 코드 작성자 -> **에이전트 조율자(orchestrator)**. 에이전트 출력 평가, 전략적 방향 제시, 문제 해결 보장
- **온보딩 혁명**: 새 코드베이스 온보딩이 **수주 -> 수시간**으로 단축. 동적 "서지(surge)" 인력 배치 가능

**사례: Augment Code**
- Claude on Google Cloud Vertex AI 사용
- 한 엔터프라이즈 고객이 CTO 추정 4-8개월 프로젝트를 **2주 만에 완료**
- *"주 단위로 걸리던 학습 작업이 이제 1-2일이면 완료된다"* - Chief Scientist Guy Gur-Ari

**협업의 현실:**
- 엔지니어들은 프론트엔드, 백엔드, 데이터베이스, 인프라 등 전 영역에서 효과적으로 작업 가능 ("more full-stack")
- AI가 지식 격차를 메우고, 인간은 감독과 방향 제시 담당
- 검증 가능하고 잘 정의된 반복 작업에 AI 활용, 고수준 설계 및 조직적 맥락이 필요한 "취향(taste)" 영역은 직접 수행

### Trend 2: 단일 에이전트에서 조율된 팀으로 진화

**핵심 예측:**
- **멀티 에이전트 시스템이 단일 에이전트 워크플로우를 대체**: 별도 컨텍스트 윈도우에서 병렬 추론을 통해 성능 극대화
- 작업 분해(task decomposition), 에이전트 전문화(specialization), 조율 프로토콜(coordination protocols) 역량 필요

**아키텍처 비교:**

```
[단일 에이전트]        [멀티 에이전트]
Task -> Agent         Task -> Orchestrator
                            ├── Agent A (전문 영역 1)
                            ├── Agent B (전문 영역 2)
                            └── Agent C (전문 영역 3)
                            -> 결과 통합
```

**사례: Fountain (프론트라인 인력관리 플랫폼)**
- 계층적 멀티 에이전트 오케스트레이션에 Claude 사용
- 스크리닝 **50% 가속**, 온보딩 **40% 단축**, 후보자 전환율 **2배**
- 한 물류 고객: 신규 물류센터 완전 인력 배치 기간을 **1주 이상 -> 72시간 미만**으로 단축

## Capability Trends: 역량 트렌드

### Trend 3: 장기 실행 에이전트가 완전한 시스템을 구축

**핵심 예측:**
- **작업 범위 확장**: 분 단위 -> **일/주 단위** 자율 작업으로 확장
- **소프트웨어 개발의 현실적 복잡성 처리**: 수십 개 작업 세션에 걸쳐 계획, 반복, 개선. 실패 복구 및 일관된 상태 유지
- **개발 경제학 변화**: 이전에 비용 대비 실현 불가능했던 프로젝트가 가능해짐. 수년간 쌓인 기술 부채를 에이전트가 체계적으로 제거
- **시장 진입 가속**: 아이디어에서 배포된 애플리케이션까지 **수개월 -> 수일**

**사례: Rakuten**
- vLLM(1,250만 줄, Python/C++/CUDA) 코드베이스에서 활성화 벡터 추출 구현
- Claude Code가 **7시간** 자율 작업으로 완료
- **99.9%** 수치 정확도 달성

### Trend 4: 인간의 감독이 지능적 협업을 통해 확장

**핵심 예측:**
- **에이전틱 품질 관리가 표준화**: AI 에이전트가 대규모 AI 생성 출력을 검토 (보안 취약점, 아키텍처 일관성, 품질 이슈)
- **에이전트가 도움 요청 시점을 학습**: 불확실성 표시, 비즈니스 영향 있는 결정 에스컬레이션
- **모든 것을 검토 -> 중요한 것만 검토**: 루틴 검증은 시스템이 처리, 새로운 상황/경계 사례/전략적 결정은 인간에게 에스컬레이션

**협업의 역설:**
- 개발자는 AI를 ~60% 업무에 사용하나, 완전 위임은 소수 작업에만 가능
- 효과적 AI 협업에는 **능동적 인간 참여**가 필수
- *"정답이 어떤 모습이어야 하는지 아는 경우에 AI를 주로 사용한다. 그 능력은 '어려운 방식으로' 소프트웨어 엔지니어링을 하면서 개발한 것이다."*

**사례: CRED (핀테크 플랫폼, 인도 1,500만+ 사용자)**
- 전체 개발 라이프사이클에 Claude Code 구현
- 실행 속도 **2배** 향상 - 인간 참여 제거가 아닌, 개발자를 고부가가치 작업으로 전환

### Trend 5: 에이전틱 코딩이 새로운 영역과 사용자로 확장

**핵심 예측:**
- **언어 장벽 소멸**: COBOL, Fortran, 도메인 특화 언어 등 레거시/비주류 언어 지원 확대
- **코딩 민주화**: 사이버보안, 운영, 디자인, 데이터 과학 등 비전통적 개발자에게 확장. Cowork 같은 비개발자용 도구 등장

**모든 사람이 풀스택으로:**
- 보안팀: 익숙하지 않은 코드 분석
- 연구팀: 데이터의 프론트엔드 시각화 구축
- 비기술 직원: 네트워크 이슈 디버깅, 데이터 분석 수행
- "코드를 하는 사람"과 "하지 않는 사람" 사이 장벽이 투과성(permeable)을 가짐

**사례: Legora (AI 기반 법률 플랫폼)**
- 법률 기술 플랫폼 전반에 에이전틱 워크플로우 통합
- *"Claude는 지시 따르기와 에이전트/에이전틱 워크플로우 구축에 뛰어나다"* - CEO Max Junestrand
- 변호사들이 엔지니어링 전문성 없이 정교한 자동화 생성 가능

## Impact Trends: 영향 트렌드

### Trend 6: 생산성 향상이 소프트웨어 개발 경제를 재편

**핵심 예측:**
- **세 가지 가속 배수(multiplier)**: 에이전트 역량 + 오케스트레이션 개선 + 인간 경험 활용이 **선형이 아닌 계단 함수적(step-function)** 개선 생성
- **타임라인 압축으로 프로젝트 실현 가능성 변화**: 수주 -> 수일
- **개발 경제학 전환**: 총소유비용(TCO) 감소, 프로젝트 타임라인 단축, 빠른 가치 실현

**생산성: 속도가 아닌 산출량 증가:**
- 작업당 소요 시간은 **순감소**하나, 산출량은 **대폭 순증가**
- 더 많은 기능 출시, 더 많은 버그 수정, 더 많은 실험 실행
- AI 지원 작업의 **~27%**는 이전에는 수행하지 않았을 작업 (스케일링, 대시보드 구축, 탐색적 작업)
- 개발자들이 더 많은 "papercuts"(삶의 질을 개선하지만 보통 후순위로 밀리는 사소한 이슈) 수정

**사례: TELUS**
- 13,000+ 맞춤 AI 솔루션 생성
- 엔지니어링 코드 **30% 빠르게** 출시
- 총 **500,000시간 이상** 절약 (AI 상호작용당 평균 40분 절약)

### Trend 7: 비기술 사용 사례가 조직 전체로 확대

**핵심 예측:**
- **코딩 역량이 엔지니어링 너머로 민주화**: 영업, 마케팅, 법무, 운영 팀이 엔지니어링 개입 없이/최소한으로 워크플로우 자동화 및 도구 구축
- **도메인 전문가가 직접 솔루션 구현**: 티켓 제출 후 개발팀 대기 병목 제거
- **생산성 향상이 전체 조직으로 확대**: 엔지니어링 시간 투입 가치가 없었던 문제 해결, 실험적 워크플로우 시도, 수동 프로세스 자동화

**사례: Anthropic 법무팀**
- 마케팅 검토 처리 시간: **2-3일 -> 24시간**으로 단축
- 코딩 경험 없는 변호사가 Claude Code로 셀프서비스 도구 구축
- 계약 수정(redlining), 콘텐츠 검토 등 반복 작업 자동화

**사례: Zapier**
- 디자인팀이 Claude artifacts로 고객 인터뷰 중 실시간 프로토타이핑 (기존 수주 소요)
- 전체 조직 **89% AI 채택**
- 내부적으로 **800+ AI 에이전트** 배포

### Trend 8: 에이전틱 코딩이 보안 방어를 개선 - 그러나 공격 활용도 증가

**핵심 예측:**
- **보안 지식 민주화**: 모든 엔지니어가 보안 엔지니어 수준의 심층 보안 리뷰, 하드닝, 모니터링 수행 가능
- **위협 행위자의 공격 확대**: 에이전트가 방어뿐 아니라 공격에도 활용됨. 처음부터 보안을 내장(build in security from the start)하는 것이 더욱 중요
- **에이전틱 사이버 방어 시스템 부상**: 자동화된 에이전틱 시스템이 머신 속도로 탐지 및 대응, 자율 위협 속도에 맞춤

**결론**: 처음부터 보안을 내장하는 에이전틱 도구를 사용하는 팀이 동일 기술을 사용하는 적대자에 대한 방어에 유리

## 2026년 우선 과제

1. **멀티 에이전트 조율 숙달** - 단일 에이전트 시스템으로는 불가능한 복잡성 처리
2. **AI 자동화 리뷰를 통한 인간-에이전트 감독 확장** - 인간의 관심이 가장 중요한 곳에 집중
3. **엔지니어링 너머로 에이전틱 코딩 확대** - 부서 전반 도메인 전문가 역량 강화
4. **초기 단계부터 보안 아키텍처 내장** - 에이전틱 시스템 설계의 일부로 포함

> *"에이전틱 코딩을 전략적 우선순위로 삼는 조직이 가능한 것을 정의할 것이며, 점진적 생산성 도구로 취급하는 조직은 새로운 규칙의 게임에서 경쟁하고 있음을 발견하게 될 것이다."*
