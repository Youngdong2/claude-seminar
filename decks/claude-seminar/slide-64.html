SECTION 5

위협 모델 — 에이전트가 위험한 4가지 이유

Anthropic이 분류한 에이전트 위협 모델 — 기술이 아니라 경계의 문제.

OVEREAGER · 과잉행동

목표는 이해했지만 승인 범위를 넘는 주도성

→ "clean up" 한마디에 원격 브랜치 전부 삭제

HONEST MISTAKES · 실수

영향 범위를 잘못 판단

→ 테스트 DB인 줄 알고 프로덕션에 실행

PROMPT INJECTION · 주입

파일·웹페이지·도구 출력에 심어진 악의적 지시

→ 읽은 문서의 숨은 지시가 파일 삭제를 유도

MISALIGNED · 정렬 문제

모델이 자체 목표를 추구 — 이론적 위험

→ 현재는 관찰되지 않지만 설계 시 가정

"can we fix this?"는 질문이지 지시가 아니다.

사용자가 승인한 것과 에이전트가 추론한 것의 경계를 명확히.
