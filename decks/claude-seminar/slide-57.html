Ralph Loop — 가장 단순한 하네스

Ralph Loop = 단 하나의 PROMPT.md 파일을 bash 무한 루프로 반복 실행하는 가장 원시적인 에이전트 패턴. 매 루프마다 에이전트가 현재 상태에서 "다음 한 걸음"을 자가 선택. Geoffrey Huntley가 정식화한 철학.

while :; do
  cat PROMPT.md | claude-code
done

왜 동작하는가

PROMPT.md에 "가장 중요한 일 하나"만 적는다

실수하면 도구 탓 말고 규칙을 추가한다

단순성이 예측 가능성을 만든다

솔직한 한계

Greenfield 전용. 레거시에 부적합

검증(테스트/린트) 없으면 환각을 쌓음

튜닝하는 엔지니어는 여전히 필요

"놀이터에서 아이가 미끄럼틀 위에서 뛰어내려 다치면, '뛰지 말고 미끄러져 내려오세요' 표지판을 세웁니다." — Huntley
