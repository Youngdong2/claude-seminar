TDD (Test-Driven Development) — 테스트 주도 개발

인간 → 테스트 작성 · AI → 통과 코드 구현.

1. [인간]

실패 테스트(Red) 작성

2. [AI]

테스트를 통과하는 최소 코드(Green)

3. [인간]

통과 코드 리뷰

4. [AI]

통과 상태 유지하며 리팩토링

TDD 지시 예시

"장바구니 할인 계산을 TDD로 구현해줘.
먼저 테스트부터 작성해:
- 기본 합계: 10,000원 × 2개 = 20,000원
- 배송비: 5만원 미만 → 3,000원,
  이상 → 무료
- 쿠폰: 'SUMMER10' → 10% 할인
테스트가 실패하는 걸 확인하고,
그 다음에 통과하는 코드를 작성해."

핵심: 인간이 테스트, AI가 구현 · 한 번에 하나 · 테스트 수정 금지
