# Claude Code 세미나 자료

전사 세미나를 위한 Claude Code 사용법 및 관련 자료 모음입니다.

## 구조

```
official/         # Claude Code 공식 문서 정리
blog/             # Anthropic 공식 블로그 및 외부 블로그 요약
youtube/          # YouTube 영상 요약 노트
linkedin/         # LinkedIn 포스트 정리
research/         # 주제별 리서치 자료
screenshots/      # YouTube 영상 슬라이드 캡처
decks/            # 발표 슬라이드
sections/         # 섹션별 발표 원고
```

## 주요 파일

- `seminar_outline.md` - 세미나 전체 구성 개요
- `presentation_outline.md` - 발표 아웃라인
- `presentation_detail.md` - 발표 상세 원고
