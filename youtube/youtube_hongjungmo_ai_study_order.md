## 1. 상한선과 하한선을 현실적으로 파악하라

- "AI가 나와서 모든 사람이 일자리를 잃을 것이다" → 상한선을 너무 높게 잡은 것
- "ChatGPT는 할루시네이션 때문에 쓸모없다" → 하한선을 너무 낮게 잡은 것
- **현실적 파악이 핵심**: 주니어 일자리는 감소 추세, 시니어는 유지/증가

---

## 2. AI가 잘하는 것 vs 못하는 것

### AI가 잘하는 것: 발산적 사고
- 나보다 아는 것이 많음
- 고정관념이 없음 → 편견 없이 다양한 아이디어 제시
- 알고리즘을 다 외우고 있음 → 갖다 붙이기를 잘함
- "돈 버는 방법" → 100가지 방법을 알려줌

### AI가 못하는 것: 수렴적 사고
- 진짜 나에게 맞는 **단 한 가지** 방법을 찾아주지 못함
- 코드를 만드는 건 잘하지만 **너무 난잡하게** 만듦
- 최적화된 하나의 해법으로 수렴시키는 것 → **결국 인간이 해야 함**

> "LLM이 만드는 답은 '한국인의 평균 얼굴' 같은 것"
> 확률적으로 답을 내놓으니 평균으로 수렴

---

## 3. 왜 다시 '컴퓨터 기초'인가?

- AI가 코딩을 다 해주지만, AI 자체도 메모리 문제가 있음 (인셉션처럼 반복)
- 돈 벌 수준의 시스템을 만들면 **다시 컴퓨터 기초 문제**를 만나게 됨
- 컨텍스트 윈도우, 토큰 최적화 → 결국 **엔지니어링 문제**
- 리트코드 600개 풀기는 조만간 없어질 것 (하지만 알고리즘 공부 자체가 불필요하다는 건 아님)

## 4. 탑다운의 함정

### 탑다운의 장점
- 동기 부여가 잘 됨
- 전체 그림을 볼 수 있음
- 제품을 빠르게 만들 수 있음

### 탑다운의 현실적 문제
- **대부분 "탑"에서 깨작깨작하다 끝남** → "다운"을 못 함
- AI 이용해서 이것저것 물어보다가 끝 → 결국 **사용자**가 됨
- 바이브 코딩 → 특정 플랫폼의 소비자로 묶여 버림
- 그 도구 없으면 아무것도 못 하는 사람이 됨

### 바텀업의 문제
- 바텀에 갇혀 버리는 함정
- 빠르게 치고 나가기 어려움

## 5. AI 시대의 올바른 공부법: "한 번만 제대로 뚫어라"

### 핵심 전략
> 아주 간단하고 쉬운 것부터 **탑다운과 바텀업을 둘 다** 해야 한다

### 방법
1. **쉬운 것으로 바닥부터 끝까지 한 번 뚫기** (투두리스트 같은 간단한 것)
2. 한 번 뚫은 것은 **평생감** → AI 시대에 두 번 다시 직접 할 일 없음
3. 머릿속에 개념만 있으면 AI가 헛소리하는지 판별 가능
4. 토큰 아끼기 가능 → "코드 쓸데없이 길게 만드는 거 알고 있으니까 줄여"

### 기하급수적 성장 구조
```
[1단계] 쉬운 것으로 탑다운+바텀업 완전히 뚫기
         ↓
[2단계] 뚫어놓은 부분은 AI가 채움 → 양쪽 조금만 보충
         ↓
[3단계] 다음 단계도 보충만 하면 됨 → 점점 빨라짐
         ↓
[결과] 기하급수적 실력 성장
```

- **인간 지능의 강점**: 일반화를 잘함 → 한 번 이해하면 확장이 쉬움
- AI가 어려운 부분을 보충 → **누구나 공부하기 좋은 시대**

---

## 6. 결론

- **변화는 현실**: 개발자의 역할이 바뀌고 있음
- **기초의 중요성**: 한 번도 뚫어보지 않은 사람은 평생 빈 공간이 남음
- **AI는 한계가 있지만 쓸모없지도 않음**: 현실적으로 파악할 것

> "성공은 한 번만 하면 된다. 한 곳을 딱 찍어서 하나 뚫으면 내 인생을 쫙 뚫고 나갈 수 있다."
