## FAQ 5가지

### Q1. 클로드랑 클로드 코드랑 무슨 차이에요?

| 구분 | Claude | Claude Code |
|------|--------|-------------|
| 정체 | Anthropic의 LLM 모델 | Claude 모델 기반 AI **코딩 에이전트** |
| 역할 | 언어 모델 자체 | 코드 생성 + 실행까지 자동화 |
| 도구 | - | 모델 + 다양한 도구(파일 수정, 웹 검색 등) 조합 |

### Q2. 클로드 데스크탑이랑 클로드 코드랑 무슨 차이에요?

**역사적 흐름:**
```
Claude 모델 개발
  → Claude 웹 (claude.com)
    → Claude 데스크탑 (채팅 탭만)
      → Claude Code (터미널 기반)
        → Claude 데스크탑에 코드 탭 추가 (Code의 GUI 버전)
          → Claude 데스크탑에 코워크(Cowork) 탭 추가
```

| 구분 | Claude 웹 | Claude Code | Claude 데스크탑 |
|------|-----------|-------------|----------------|
| 인터페이스 | 브라우저 채팅 | 터미널 CLI | 네이티브 앱 GUI |
| 파일 접근 | 업로드만 가능 | 로컬 폴더 직접 접근 | 로컬 폴더 직접 접근 |
| 코드 실행 | 클라우드 서버(격리 환경) | 내 컴퓨터에서 직접 실행 | 둘 다 (채팅=클라우드, 코드=로컬) |
| 아티팩트 | O | X (직접 파일 생성) | O (채팅 탭) |
| 딥 리서치 | O | X | O |
| 대상 | 일반 사용자 | **개발자** | **모든 사용자** (채팅+코드+코워크) |

**성능 차이**: 동일한 Claude 모델 사용. 단, 시스템 프롬프트와 도구 구성이 다르므로 체감 성능은 다를 수 있음.

> **데스크탑 코드 탭** = Claude Code의 GUI 버전 (GUI냐 CLI냐의 차이)

### Q3. 터미널은 뭐에요?

- 어원: 라틴어 "끝점(Terminus)"에서 유래
- **컴퓨터에게 명령을 내리는 창**
- 옛날에 중앙 컴퓨터의 끝단에 연결된 입출력 장치 → 터미널
- 버튼 없이 텍스트로 직접 명령을 보내서 실행

**Mac 터미널 종류**: iTerm, Ghostty, Wezterm 등 (취향 차이)
**Windows**: PowerShell, CMD 등

**핵심**: 터미널에서 여러 창을 동시에 띄울 수 있음 → "클로드 코드 4개 동시에 돌린다"는 것 = 여러 창을 띄운 것

### Q4. CLI는 뭐에요?

- **CLI** = Command Line Interface (명령줄 인터페이스)
- **GUI** = Graphic User Interface (그래픽 사용자 인터페이스)

| 비교 | GUI | CLI |
|------|-----|-----|
| 반복 작업 | 파일 100개 이름 바꾸기 → 하나씩 클릭 | 반복 명령어 한 줄로 해결 |
| 조합 | 메뉴에 있는 버튼만 | 명령어끼리 자유롭게 조합 |
| 자동화 | 어려움 | 스크립트(.sh, .bat, .py)에 저장 → 한 번에 실행 |

### Q5. VS Code/Antigravity에서 클로드 코드 쓰는 거랑 터미널이랑 차이가 있어요?

**IDE (Integrated Development Environment) = 통합 개발 환경**
- 코드 확인 공간 + 개발 편의 도구 + **내장 터미널**
- IDE 안의 터미널에서 Claude Code 실행 = 일반 터미널에서 실행과 **동일**

**VS Code 구성:**
- 왼쪽: 파일 탐색기 (코드 저장 위치)
- 중앙: 코드 상세 내용
- 하단: 터미널 (여기서 `claude` 실행)
- 확장 프로그램: Claude 웹 형태로도 실행 가능

**Antigravity:**
- VS Code 기반으로 수정된 IDE
- 구조 동일 (왼쪽 코드 + 중앙 내용 + 하단 터미널)
- 우측에 에이전트 탭 추가 (Gemini, Claude Opus 등 선택 가능)

**왜 터미널을 선호하는가?**
- 코드 생산량이 너무 많아져서 사람이 다 볼 수 없음 → 코드를 거의 보지 않음
- 습관/취향 영역 — 뭐가 더 좋다는 아님
- 처음이라면 **코워크 탭**이나 **데스크탑 코드 탭**에서 시작하는 것도 좋음

## 핵심 정리

```
Anthropic (회사)
  └── Claude (LLM 모델: Opus, Sonnet, Haiku)
        ├── Claude 웹 (claude.com) — 브라우저 채팅
        ├── Claude Code — 터미널 기반 AI 코딩 에이전트
        └── Claude 데스크탑 앱
              ├── 채팅 탭 — 웹과 유사
              ├── 코드 탭 — Claude Code의 GUI 버전
              └── 코워크 탭 — 로컬 파일 연동 AI 에이전트
```

> 클로드 코드가 어렵다면 → **코워크 먼저** 써보는 것을 추천
